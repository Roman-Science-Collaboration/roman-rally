{%- comment -%} Renders a front-matter value. An empty value, or the old header sentinel **TBD** / TBD, is shown as "To be announced" so the word never reaches a page. {%- endcomment -%} {%- assign raw = include.value | append: "" | strip -%} {%- if raw == "**TBD**" or raw == "TBD" or raw == "" -%} To be announced {%- else -%} {{ raw }} {%- endif -%}
